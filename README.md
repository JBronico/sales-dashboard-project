# sales-dashboard-project
Beginner sales analysis using Google Sheets

## Project Title
Sales Performance Dashboard - Case Study

## Objective
Analyze sales data to identify key performance trends across prodyct categories, regions, and time. The goal is to understand what drives revenue and where improvements can be made.

## Data Source
- Supertstore sales dataset (CSV)
- Fields include: Sales, Category, Region, Order Date, and Order ID

## Tools Used
- Google Sheets
- Pivot Tables
- Charts
- Basic data cleaning

## Data Preparation
  - Removed duplicate rows
  - Fixed date formatting issues (converted text dates into proper date format)
  - Verified numeric fields (Sales) were correctly formatted
  - Created cleaned dataset for analysis

## Key Insights
 - Technology category generated the highest total sales compared to other categories
 - Certain regions consistently outperformed others in total revenue
 - Sales showed clear montly variation, inidicating season trends
 - A small number of categories drove most of the revenue (uneven distribution)

## Business Recommendations
- Focus marketing efforts on top-performing categories to maximize return
- Investigate underperforming categories for pricing or demand issues
- Adjust inventory planning based on seasonal sales trends
- Prioritize high-performing regions for expansion strategies
